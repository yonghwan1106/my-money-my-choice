## 2. 생성 규칙과 출처

- 규칙 정본: `pipeline/gen_synth.py`, 통계값: `pipeline/config/stats_sources.yaml`.
- 생성 규칙은 신호·모델을 만들기 **전에** 커밋했습니다 — 커밋 `4c3e2e9`(태그 `gen-frozen`). 그 뒤 신호 동결 `c2d04be`(`signals-frozen`), 모델 동결 `cdc12e9`(`model-frozen`) 순서입니다(`data/eval/provenance.json`).
- **공개 통계에 묶은 값**: 경제적 착취 지속기간 분포와 행위자 비율 — 보건복지부·중앙장애인권익옹호기관, 「2024 장애인학대 현황보고서」 151쪽([표 5-15]·행위자 본문). 행위자는 지인 0.358 · 사회복지시설 종사자 0.149 · 모르는 사람 0.110 · 형제자매 0.074 · 나머지 0.309(나머지는 직접 묶은 범주). 실제로 뽑힌 비율은 `summary.json`의 `perpetrator_share`(목표와 ±2%p 안).
- **가정값(근거 통계 없음)**: 수법 비율(P1~P6 같게), 집단 비율(새로 시작 120 : 이미 진행 중 120), 강도 비율(높음·중간·낮음 같게), 급여·수당·생활비·착취 금액 전부, 가게·적요 이름.
- 평소 흐름(전원): 급여 70%, 수당 90%, 카드 생활비(하루 평균 1.5건), 자동이체(월세·관리비·통신·보험), 가족·친구 송금, 현금 인출, 소액결제 — 세부 범위는 `gen_synth.py`.

## 4. 다시 만들기

```
python -E <저장소>\pipeline\gen_synth.py --check
```
- 600명을 `pipeline/work/synth/`에 만들고 집단·수법·형식·인코딩·행위자 비율을 검사해 `CHECK OK`와 `truth_sha256`을 출력합니다. 위 해시와 같아야 합니다(`--out <폴더>`로 다른 곳에 만들 수도 있음).
- Python 패키지 버전은 `pipeline/requirements.txt`. 특징 추출은 Python이 아니라 화면과 같은 TypeScript 엔진으로 합니다: `npx --prefix <저장소> tsx <저장소>\scripts\featurize.ts --in <저장소>\pipeline\work\synth --out <저장소>\pipeline\work\features.csv`.

## 6. 한계

- 우리가 만든 가상 거래 기록이라 실제 성능을 말해 주지 않습니다. 데이터를 만든 사람과 모델을 만든 사람이 같은 팀이라 결과가 좋게 나올 수 있습니다.
- 착취 수법별 비율·금액은 공개 통계가 없어 가정했습니다. 은행 적요 이름과 형식 2종은 실제 은행 파일을 흉내 낸 것으로, 실제 은행마다 다를 수 있습니다.
- 지속기간이 26주보다 긴 착취는 기간 안에서 잘립니다. 실제 기록에서는 평소 흐름 자체가 더 불규칙할 수 있습니다.
- 발달장애인 당사자와 함께 검토한 데이터가 아닙니다.
